# Generic-name test system for the new PUMP node type.
#
# Numbering convention (hard requirement, enforced in
# Pump::ValidatePumpSettings): a PUMP's idnr must be strictly LOWER than
# BOTH its PUMP_SOURCE_IDNR and PUMP_TARGET_IDNR, since Herss::Simulate()
# is single-pass (each node Simulate()'d exactly once per t, in ascending
# idnr order) - the pump must always run before either reservoir it
# touches so its withdrawal/injection is visible to them later in the
# SAME timestep. Hence pump_AB is numbered first (0), before both
# reservoir_A (its target) and reservoir_B (its source).
##########################################################################
