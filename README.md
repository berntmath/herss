HERSS (The Hydraulic Economic River System Simulator) is a simulation tool for hydropower
river systems, modeling reservoirs, powerstations, intakes, pumps, and channels connected in a river
network. It computes the physical water balance and the associated economic value
(production, cost, and revenue) of a given operational strategy over a chosen time
horizon. HERSS can be used inside Python (cppyy) . 

For detailed instructions on how to install and run the HERSS model please read the user manual.
It is located under the ./doc folder. Look for the file herss.pdf
