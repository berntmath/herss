# TOPOLOGY FILE - mini_tailwater_test
# Andreas, November 2026
# Test system for TAILWATER_IDNR in a PSTATION node.
#
# PUMP (0) pumps water from Reservoir_B up to Reservoir_A, and
# HYDRO_POWERSTATION_A (2) releases the same water from Reservoir_A back
# down to Reservoir_B. Without TAILWATER_IDNR, HYDRO_POWERSTATION_A
# computes Hbrutto down to POWSTAT_MASL. With TAILWATER_IDNR 3, it computes
# Hbrutto down to the water surface elevation of Reservoir_B, as PUMP does.
# See README.md.
#
# Numbering convention (hard requirement, enforced in
# Pump::ValidatePumpSettings): a PUMP's idnr must be strictly LOWER than
# BOTH its PUMP_SOURCE_IDNR and PUMP_TARGET_IDNR. Hence PUMP is numbered
# first (0), before Reservoir_A (its target) and Reservoir_B (its source).
##########################################################################

#######################################################################################
# Pump - lifts water from Reservoir_B up to Reservoir_A
# Numbered first (0) so both source and target have a HIGHER
# idnr than the pump, per the hard numbering requirement above.
